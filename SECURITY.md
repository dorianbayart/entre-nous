# Signaler une faille de sécurité

Merci de **ne pas ouvrir d'issue publique** pour une faille : utilise le signalement privé de
GitHub (**Security → Report a vulnerability** sur ce dépôt). Décris ce que tu as trouvé, comment
le reproduire et ce qu'un attaquant pourrait en tirer.

Le modèle de sécurité (ce que le serveur relais voit et ne voit pas, algorithmes, limites connues)
est décrit dans [docs/securite.md](docs/securite.md).
