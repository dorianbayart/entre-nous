# Reporting a security vulnerability

Please **don't open a public issue** for a vulnerability: use GitHub's private reporting
(**Security → Report a vulnerability** on this repository). Describe what you found, how to
reproduce it, and what an attacker could gain from it.

The security model (what the relay server sees and doesn't see, algorithms, known limitations)
is described in [docs/en/security.md](docs/en/security.md).
