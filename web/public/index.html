Comment ça marche

  1. Installe Entre Nous sur un premier appareil ou lance l’application web.
  2. Ajoute tes autres appareils en scannant un QR code. Aucun compte à créer.
  3. Copie, colle. Textes, photos, fichiers : tout passe d’un appareil à l’autre en un instant.

Entre nous, et personne d’autre

  • Confidentiel. Ce que tu transfères est chiffré sur ton appareil, et voyage sur une connexion elle-même chiffrée.
  • Éphémère. Tout s’efface automatiquement. Choisis la taille de l’historique et le temps de rétention du presse-papier.
  • Sans compte. Pas d’inscription, pas d’e-mail, pas de mot de passe.
  • Sans pistage. Pas de publicité, pas de traceur, pas de log.
  • Open source. Le code est public, sous licence AGPL : chacun peut vérifier ce qu’il fait. Voir le code sur GitHub

Installer

Android

Télécharge l’appli et ouvre le fichier. Android te demandera d’autoriser l’installation : Entre Nous ne passe pas par le Play Store.

Entre Nous apparaît ensuite dans le menu Partager de toutes tes applis.

Sans rien installer, l’appli web fonctionne aussi dans Chrome.

iPhone et iPad

Ouvre l’appli web dans Safari, puis Partager → Sur l’écran d’accueil.

Lance Entre Nous depuis cette icône pour ajouter ton iPhone, et non depuis Safari.

Mac

Décompresse le fichier et glisse Entre Nous dans Applications. L’appli se loge dans la barre des menus, en haut de l’écran. Pour envoyer un fichier, glisse-le sur son icône.

Au premier lancement, macOS la bloque car elle n’est pas encore validée par Apple : va dans Réglages Système → Confidentialité et sécurité, puis clique sur Ouvrir quand même.

Si ton Mac demande l’accès au trousseau, choisis Toujours autoriser.

Windows

Télécharge l’installeur et lance-le. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires, puis Exécuter quand même : Entre Nous n’est pas encore signé par un éditeur reconnu.

L’appli se loge dans la zone de notification, en bas à droite de l’écran. Pour envoyer un fichier, glisse-le dans sa fenêtre.

Linux

Sur Debian, Ubuntu et leurs dérivées, installe le paquet .deb. Ailleurs, télécharge l’AppImage, rends-la exécutable et lance-la.

L’appli se loge dans la zone de notification. Sous GNOME, il faut l’extension AppIndicator pour voir son icône. Pour envoyer un fichier, glisse-le dans sa fenêtre.

Autres appareils

Rien à installer : l’appli web fonctionne dans tout navigateur récent. Colle (Ctrl+V) ou glisse un fichier pour l’envoyer.

Questions fréquentes

Qui peut lire ce que je partage ?

Tes appareils, et personne d’autre. Pas même nous. Le code est open source : chacun peut le vérifier.

Combien de temps mes données sont-elles gardées ?

24 heures par défaut. Tu peux choisir 10 minutes, 1 heure, 24 heures ou 7 jours. Passé ce délai, tout s’efface.

Et si je perds un appareil ?

Retire-le depuis un autre de tes appareils : il perd aussitôt l’accès à tout ce que tu partages.

Faut-il installer quelque chose ?

Pas forcément : l’appli web fonctionne dans tout navigateur récent. Les applis vont plus loin : partage depuis n’importe quelle appli sur Android, et copie automatique sur Mac, Windows et Linux.
